## [Unreleased]

### Added
- Проект инициализирован переносом кода из `../ТГ агент` под `agentic-coding-template` pipeline
  (2026-07-23): amoCRM ↔ Telegram/Email агент партнёрского отдела Альбато, классификация ответов
  клиента через Claude. Сценарий и бизнес-логика не менялись, только структура проекта
  (AGENTS.md, RESEARCH.md, CLAUDE.md, WORKFLOW.md, `.claude/`, `tasks/`, `templates/`, `docs/`).
- **Cutover (2026-07-23):** runtime-состояние (`data/telegram.session`, `data/app.db`,
  `data/agent.log`) перенесено из `../ТГ агент` — этот проект теперь единственный источник
  боевого состояния, `../ТГ агент` decommissioned (код-архив без данных).
- **Анти-бан вариации первого сообщения (2026-07-23):** `core/templates.py` — 4 формулировки
  первого сообщения, случайный выбор при каждой отправке (`FIRST_MESSAGE_VARIANTS`).
- **База знаний (FAQ) на встречные вопросы клиента (2026-07-23, черновик):**
  `classify/faq.py` + `docs/faq-knowledge-base.md`. При ambiguous-ответе бот пытается подобрать
  готовый ответ из базы через Claude (`match_faq_sync`), отвечает клиенту и всё равно ставит
  задачу на Варвару с пометкой, что дан автоответ. ⚠️ Тексты ответов — плейсхолдеры, ждут
  реальных фактов (цены/сроки/условия) в `docs/faq-knowledge-base.md`.
- **Чеклист целостности задачи (2026-07-23):** `core/checklist.py` — стек: минимум 2 названных
  сервиса; кейс: описана проблема клиента ИЛИ данные для обработки (через Claude, фолбэк — длина
  строки). Не блокирует и не откладывает отправку — если данных не хватает, бот вставляет
  предупреждение прямо в основное первое сообщение, перед абзацем согласия на оплату
  (`core/templates.py: first_message`).

## Convention

- **Added** — новая функциональность
- **Changed** — изменения существующей функциональности
- **Deprecated** — функциональность будет удалена
- **Removed** — функциональность удалена
- **Fixed** — багфиксы
- **Security** — security фиксы

Каждая запись = ссылка на PR + краткое описание для пользователя (не для разработчика).
